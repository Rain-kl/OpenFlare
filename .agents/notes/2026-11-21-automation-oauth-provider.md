# 自动化授权与 MCP 连接设置

CLI 和 MCP 的授权码、S256 PKCE、令牌签发、轮换、回放处理和撤销由 Ory Fosite 执行。数据库适配器保存 Fosite 会话及签名哈希。授权码与 PKCE 会话一起写入，令牌交换中的 PKCE 校验、授权码消费和令牌写入共享事务，验证失败时回滚。授权请求以绑定管理员会话的短期签名凭证传给控制台静态页，凭证位于 URL 片段，确认时通过表单提交。授权页采用同源 Referrer Policy，浏览器表单可发送真实的 Origin；后端仍严格校验 Origin。

MCP 设置复用现有的连接地址配置，由系统设置标签页展示连接参数。管理员可逐项选择权限并生成有效期 30 天的 MCP 专用令牌。专用令牌无法调用 CLI REST 端点，不提供刷新令牌，明文只在生成时返回。账户级撤销会清理 OAuth 会话及专用令牌。Canary 自实现 OAuth 版本签发的旧令牌需要重新授权。
