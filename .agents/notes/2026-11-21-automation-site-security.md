# CLI 与 MCP 站点安全管理

- 从 Swagger 生成结构化对象、字符串映射、对象数组和 DELETE 操作契约。CLI、REST 和 MCP 共用参数校验；解析嵌套 JSON 时拒绝重复键，封闭显式属性对象，保留映射键。既有操作的生成契约保持不变。
- 安全读取和写入分别要求 `security:read` 与 `security:write`。站点设置查询仅返回认证模式和响应头名称，IP 组查询不返回订阅地址、订阅错误原文和来源配置。
- 站点设置、认证、PoW 和新增 WAF 绑定在同一站点记录锁下写入。WAF 绑定保持原有流程顺序。攻击防护组删除和流程图保存通过攻击防护组行锁协调，避免生成悬空引用；SQLite 由事务的写入串行化保证一致性。
- 节点健康查询重用分页节点状态和应用记录查询，按页批量读取活跃健康事件，整页只读取一次控制端目标快照。连接状态、最后报告的运行健康和配置同步分别返回。
