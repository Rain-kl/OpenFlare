# Edge 单二进制安装

在安装目录内暂存经过校验的程序，通过原子重命名安装到固定入口 `current`。旧版本目录只在替换成功后清理。保留同一路径使旧 systemd 单元和手动启动命令可以继续使用。安装和更新共用安装目录的文件锁。

更新器先校验并暂存新程序，再依次运行 `systemctl stop`、原子替换程序和 `systemctl start`。就绪交由 systemd 的 `Type=notify` 管理。启动失败提取日志并保留已安装程序，后续可以重试。

安装和更新在锁被占用时立即退出。关闭传给 `systemctl` 的锁文件描述符，避免终端中断后由遗留的 `systemctl` 进程继续持有安装锁。

此前的发行版验证记录和二进制回退已移除。节点配置快照的恢复机制由边缘运行时负责。
