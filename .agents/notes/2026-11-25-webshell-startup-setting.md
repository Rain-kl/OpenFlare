# 节点远程执行启动开关

- Server 启动时读取顶层 `enable_webshell`。Viper 将 `ENABLE_WEBSHELL` 绑定到同一个配置键，默认值为 `false`，运行期使用启动时的配置快照。
- 控制台与自动化接口共用 `exec.RunCommand`，该入口在节点查询和任务写入之前拒绝远程执行。控制台与自动化 REST 返回 HTTP 403，MCP 返回工具错误。
- WebSocket 下发和 Redis 转发到本地节点时均检查当前实例的启动开关。跨实例下发要求接收请求和连接节点的实例均启用该开关。
- 已有任务可继续查询和删除，节点可回传重启前下发任务的结果。
