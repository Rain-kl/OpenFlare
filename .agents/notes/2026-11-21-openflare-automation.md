# OpenFlare CLI 与 MCP

- 契约从 Swagger 的显式自动化声明生成，操作 ID、参数、权限和 DTO 由 REST、Cobra 和 MCP 共用。REST 写操作校验连接实例和契约摘要。
- OAuth 采用浏览器授权码与 S256 PKCE。只读和日常运营档位由用户选择，已授权操作不逐次确认；CLI 和 MCP 令牌用途隔离且每次查验当前管理员资格。
- 直连站点沿用代理规则配置；域名追加与换源使用窄更新，性能策略单项更新在事务中读取和校验原值。站点写入触发现有快照构建，性能策略沿用配置变更通知。
- `TestOperationsWorkflow` 通过 HTTPS REST 与 MCP 验证从授权、域名登记到站点快照，再到单项调参、日志与节点指标。
