# Pingora 本地部署与发行包契约

US-OCI-A1 使用来自主分支的安装器，但能下载的 Edge 发行包仍是基于 `4d692f94` 的 `edge-v0.1.0`。该二进制只有旧版数据面启动路径，等待就绪通知的 systemd 单元在 90 秒后超时。同一节点在主控已登记为 OpenResty，因此旧节点身份也不能直接获取 Pingora 快照。

节点详情中的 Linux 脚本命令使用专属令牌类型 `node`。当前契约的 Edge 使用原令牌注册时，控制端仅在 Pingora 发布已生效时迁移现有 OpenResty 节点。注册和心跳写入按原引擎与令牌校验，避免迁移后旧心跳覆盖状态。Edge 启动时会使用节点令牌重新注册，包括已保存身份的节点。

Edge 运行和发行版本更新为 `0.1.1`，安装器对旧包在修改节点前报错。发行工作流验证 Linux 就绪通知。
