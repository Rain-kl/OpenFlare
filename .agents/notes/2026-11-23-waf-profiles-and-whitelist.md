# 攻击防护等级与全局白名单

Edge 的必要防护与平衡防护采用显式规则 ID 预设。必要防护包含 22 条规则，平衡防护包含 64 条。泛化检测规则 `942100` 从平衡预设移除。逐条设置仍优先于预设，高强度及仅观察仍加载所选类别的全部规则。前端从 Edge 生成的目录读取 `essential` 和 `balanced`，计算继承动作及运行数量。

`of_waf_request_whitelist` 的增删改通过数据库触发器标记站点快照需要更新。快照包含非空白名单时要求 `waf-request-whitelist-v1`，旧 Edge 会继续使用前一份有效快照。Edge 应用快照时编译正则，按精确域名和一级泛域名索引。请求同时匹配域名和原始路径时，Edge 跳过全部 WAF 流程及其请求体检测。站点认证、独立 PoW 与限流沿原有入口执行。

规则组列表导航至 `/attack-protection/editor`。编辑入口追加 `id`，直接访问可从控制端重新加载已有规则组。保存成功后刷新列表缓存并返回攻击防护页。
