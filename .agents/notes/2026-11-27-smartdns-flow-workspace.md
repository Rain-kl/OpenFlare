# SmartDNS 可视化编排

原画布的受控节点由策略图重新生成。浏览器复现时，默认节点和新节点都存在于 DOM，但可见性为 hidden，连线数量为零。React Flow 的尺寸事件未写回受控节点，节点内部没有稳定的尺寸和端口数据。

编辑器在单独的静态兼容路由读取策略。React Flow 的测量、拖拽过程和选中状态在画布内维护，拖动完成后再将位置写入策略图。条件节点按分支渲染独立端口，增删和排序分支后重新测量。删除分支或节点时同步移除对应连线。

可视化图与原始 JDM JSON 分别由明确的策略模式提交。查看编译结果时保存来源仍为可视化图。

筛选下拉复用国家目录，并直接读取节点标签与节点线路分组。历史策略中的已选值仍可查看和移除。画布删除按键只在画布拥有焦点时处理，同属性面板共用删除逻辑。拖放坐标通过 React Flow 当前视口转换。
