# 节点列表监控

`/nodes` 使用 `GET /api/v1/d/nodes/page`，每页请求 50 条，启用 `include_monitoring`。列表和卡片共用资源条、状态展示、延迟摘要和纵向操作。节点名称下展示地区、IP 和操作系统，状态集中显示连接状态与在线节点的运行健康。两个版本字段分别保留。延迟历史在展开时加载共享折线图，失败样本在曲线中保留断点。

分页业务层仅对当前页读取操作系统名称，并从活动日志库批量读取在线节点最近 5 分钟的资源快照。延迟按任务权重选择每个节点前 3 个已绑定任务，每项按探测间隔读取最多 12 条近期样本。ClickHouse 按分组限量，PostgreSQL 和 SQLite 使用窗口排名。监控数据读取失败时，节点列表及管理操作仍然可用。

搜索沿用服务端字面子串匹配，并支持地区和操作系统名称。现有列表、详情和自动化查询按原有契约返回，控制台分页通过可选参数获取监控字段。
