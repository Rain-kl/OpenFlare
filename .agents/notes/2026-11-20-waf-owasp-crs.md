# Pingora WAF 接入 OWASP CRS

Edge 内置 OWASP CRS 4.30.0 的请求初始化、检测规则和依赖词表。上游文件保留原样，来源和归档哈希记录在 `edge/pingora/vendor/owasp-crs/README.md`。解析规则时使用私有临时目录解析词表路径，完成快照编译后清理该目录。

规则组、流程图及访问日志协议沿用现有结构。平衡防护选择 PL1，高强度及仅观察选择 PL1 至 PL4。移除未映射或未启用的检测规则时，由引擎同时移除串联规则的后续条件。CRS 异常评分拦截由流程图的分支机制接管。CRS 请求规则没有独立的 XML 外部实体和 ASP 代码注入规则族，保留对应的四条 OpenFlare 补充规则及原 ID。

zentinel-modsec 固定至上游 v0.6.0 的 Git 提交。该版本修复了失败的串联规则出现在 `matched_rules`、串联条件读不到捕获变量及条件中的 `setvar` 等问题。日志使用规则原始 `msg`，沿用现有 16 条上限，不上报请求匹配值。引擎现有的 SecLang 兼容性决定具体规则可用范围。
