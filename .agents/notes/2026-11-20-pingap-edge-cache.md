# Pingap 边缘缓存存储

将 Rust 边缘代理的 HTTP 响应存储切换为固定提交的 pingap-cache。容量为 0 时使用 TinyUFO 内存缓存，设置磁盘容量后在节点状态目录的 http-cache 中启用文件缓存和 TinyUFO 热层。Pingap 管理对象存储、淘汰、并发与最近访问时间，边缘后台服务定时清理长期未访问文件。可用内存沿用节点硬件探测，磁盘对象上限亦考虑整对象读取所需的内存。

性能参数沿用现有策略和配置同步接口。新增磁盘参数随启动参数重载，旧策略缺失字段时继承内存模式与磁盘默认参数。缓存键隔离协议、域名、完整 URI、快照摘要和单对象有效上限，降低节点容量后只读取符合当前上限的条目。传给 Pingap 的键经过预哈希，避免查询参数进入库的存储日志。磁盘初始化失败时保留内存缓存和代理服务。

验证覆盖旧策略解码、API 参数范围、前端策略编辑、内存命中、磁盘落盘和重启后命中。
