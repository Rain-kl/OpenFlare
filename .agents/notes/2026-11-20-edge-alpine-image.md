# Edge Alpine 镜像

容器通过 Alpine Rust 工具链构建静态 musl 二进制。构建阶段移除符号，并通过 ELF 程序头和动态段检查可执行文件是否依赖动态加载器或共享库。Alpine 运行层自带 BusyBox 和系统 CA 证书，入口脚本、健康检查、UID/GID 和状态卷沿用现有配置。

镜像发布工作流从构建元数据指定的源码提交构建 amd64 和 arm64 镜像。Linux 安装包仍使用原生 glibc 构建产物。镜像发布层采用最高级别的 gzip 压缩，保留现有镜像客户端的兼容性。

ARM64 镜像按同一源码对照，从 133 MB 降至 29.4 MB，压缩镜像层约 14.2 MB。测试工作流运行原生单元测试和 Linux 原生二进制测试。
