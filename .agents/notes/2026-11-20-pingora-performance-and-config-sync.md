# Pingora 性能策略与统一配置同步

- 性能策略由控制端持久化。节点通过可空策略 ID 关联一条策略。批量替换分配和删除使用数据库事务，非法节点导致整批回滚。
- 配置清单通过心跳返回，WebSocket 和 Redis 广播只携带变更通知。站点快照沿用发布序号和已保存的内容哈希，WAF IP 组按当前快照引用范围授权。所有拉取共用一个接口并验证内容 SHA-256。资源描述符携带可选的提供者元数据。
- 上游参数和缓存请求参数在 Rust 数据面实时替换。回源连接组号随相关策略变更递增，避免使用旧选项创建的连接。启动参数持久化后重新执行节点程序，使运行时、TLS、监听套接字和缓存容量重新初始化。
- 新发布版本只写入 Pingora 站点快照。历史发布的业务数据和资产仍可用于首次发布衔接，已移除 OpenResty 运行时、配置接口和独立发布开关。
