# OAuth 授权页按组选择权限

- 授权页按 `:read` 和 `:write` 后缀分组，只显示客户端实际请求的权限。每组默认关闭，读写可独立选择；列表内保留具体权限名称以供核对。
- 权限明细默认折叠，点击组标题控制展开状态，授权开关独立控制表单提交的 scope。明细随内容撑开，避免在授权页内嵌套滚动区域。
- 分组只影响授权页交互。表单仍提交具体 scope，服务端继续将其与当前授权请求的 scope 白名单核对。
- 授权确认后，OpenFlare 将浏览器重定向到 OAuth 客户端注册的回调地址。Codex 的本地回调服务器负责渲染认证完成页，OpenFlare 授权页的样式无法影响该响应。
