# 节点实时运行日志

浏览器从节点详情的「日志」标签页发起管理员 SSE 请求。主控沿用 Edge 主动建立的 Agent WebSocket，每条节点连接只维护一个采集订阅，同节点的多个查看者复用。先等待节点确认，再开始 SSE。旧版 Edge 未确认时，主控返回 HTTP 503。

Edge 将与本机相同日志级别的 tracing 事件输出到有界内存队列，只在存在实时订阅时格式化和转发。每行最多采集 4096 字节，每批最多 8 条，积压时报告跳过数量。慢速查看者从实时流中断开，避免阻塞控制连接。

同副本直接转发。跨副本使用按查看者划分的 Redis Pub/Sub 主题，确认后才开启浏览器流。断开 SSE 即移除本地订阅，跨副本转发端最晚在下一个 10 秒心跳发现订阅已结束。Edge 租约兜住停止指令未送达或连接异常的情况。Redis 命令追踪对日志正文只记录占位符。主控没有日志持久化路径，浏览器只在当前标签页保留最近 500 条。
