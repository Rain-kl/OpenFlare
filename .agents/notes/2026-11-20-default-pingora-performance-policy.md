# Pingora 默认策略与自动配置

默认策略复用预置策略的唯一键。Goose 在两种数据库中创建该策略，保留既有节点分配。节点心跳和配置拉取均实时读取有效策略，显式分配优先，未分配时继承默认策略。默认策略支持编辑参数，删除和显式批量分配受接口保护。取消分配或删除普通策略后，节点再次继承默认策略。

自动配置保留既有的 `threads_auto` 协议字段。Edge 启动时按进程可用 CPU 核心数和内存上限计算线程与回源连接池。Pingora 根据每线程配置值乘以线程数确定连接池容量，因此自动配置将内存对应的总容量分摊到各线程。Linux 节点在常见挂载下读取进程所属 cgroup 及其父级限制，取最严格的值。手动模式使用保存的固定参数。
