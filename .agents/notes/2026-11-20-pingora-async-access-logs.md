# Pingora 访问日志异步落盘

- 代理结束请求时转移日志字段并尝试入队；请求路径不再启动阻塞任务、获取文件锁或同步磁盘。日志记录内存按实际堆分配计量，覆盖 WAF 规则列表和请求预览。
- 独立写线程按 256 条或 100 毫秒批写。正常停机、热升级及性能策略触发的重新执行均在 Pingora 运行时退出后排空并等待写线程；内存超限或批写失败按周期汇总告警。
- 复用原有 JSONL、随机记录 ID、跨进程 `flock` 与磁盘保留策略。写入和确认不能覆盖彼此的更新；心跳只读取持久化记录，控制端确认后按 ID 移除。溢出时直接原子替换，不先把完整批次追加到已有文件再写第二次。
- 性能报告中的 `tmpfs` 数据来自逐请求同步实现，仅用于定位瓶颈。部署异步版本后应保持物理磁盘、负载、线程和 WAF 策略不变复测，同时检查日志上报量与丢弃告警。
