# Edge 构建、测试与发布拆分

保留原构建工作流路径以延续 Canary 运行编号。构建产物记录同一次运行的版本、源码提交和发布渠道。Release 与 Docker 工作流经 workflow_run 从同仓库的成功构建下载双架构二进制，分别发布。两个发布工作流须存在于默认分支。测试按边缘节点相关路径触发，使用独立的调试编译及缓存。

Rust 依赖缓存按目标架构与 Release、测试用途区分。默认分支上的依赖和构建配置变更在缓存未命中时填充 Release 缓存，Canary 也可写入本分支缓存。标签构建复用默认分支缓存。Docker 发布从 GHCR 读写分架构的 BuildKit 缓存，容器依赖和入口文件在版本变化时仍可复用。手动重建沿用已有标签与源码，Docker 发布只更新该版本的镜像标签。
