# NetIntel BGP 前缀索引

- BGP 前缀按地址族存放，IPv4 与 IPv6 的分桶哈希表和按 ASN 排序的列表都保存行号。ASN 查询直接读取预计算的地址族计数，分页按需生成当前页的 CIDR 文本。
- 加载阶段为单个 ASN 暂存排序用的 CIDR 字符串，保留 Hits 降序和 CIDR 文本升序。同一前缀的重复记录完整进入 ASN 列表，最长前缀匹配读取最后一条。
- JP-OCI-A1 的 ARM64 独立进程使用线上同一份数据交替运行三轮。加入 BGP 优化后，NetIntel 回收后常驻堆中位数约 311 → 165 MiB，热更新峰值 RSS 约 936 → 530 MiB，热更新耗时约 4.48 → 3.35 秒。与原始实现对照的 10 万次 IP 查询、抽样 ASN 分页和拓扑结果摘要一致。
- 混合负载的首轮对照中，IPv6 查询 P99 从 29.28 µs 上升至 39.92 µs。固定 CPU 和数据，单独复测 IPv6，每版 15 批、每批 5 万次查询，P95 中位数为 17.08 → 16.60 µs，P99 中位数为 32.00 → 31.64 µs，未重现此前的回退。
- 内置 SmartDNS 进程内处理器使用单节点测试快照和相同 NetIntel 数据，每版三轮、每轮每种记录类型 2 万次请求，全部走缓存未命中路径。A 请求 P95/P99 中位数为 38.20/106.68 → 32.72/57.64 µs，AAAA 为 40.84/116.64 → 35.00/85.68 µs。测量范围是请求处理器，不含套接字传输。
