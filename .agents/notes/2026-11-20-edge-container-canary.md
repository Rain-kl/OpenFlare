# Edge 容器与 Canary 发布

Edge Docker 镜像使用非 root 用户运行，容器监听 8080 和 8443，节点身份与快照写入数据卷。启动脚本支持令牌和令牌文件，容器就绪沿用运行时生成的 ready.json。容器更新通过重新拉取镜像并复用数据卷完成。

发布工作流按架构构建原生二进制，归档与容器共用同一份二进制。两个架构均通过运行时和容器测试后，发布镜像清单和 GitHub Release。Canary 推送基于最近的正式标签生成下一修订的预览版本，并更新 canary 镜像。正式标签推送更新 latest，手动重建只发布对应版本的镜像。

默认安装脚本跳过预览标签。控制端发布查询和节点自动更新在当前页面缺少合适版本时继续翻页，以便在大量 Canary 发布后找到正式版本。
