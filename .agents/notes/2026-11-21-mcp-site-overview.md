# MCP 站点与流量概览

- 站点盘点走 `openflare_site_overview`，REST、CLI 和 MCP 使用 Swagger 生成的同一契约。契约的 `requires` 为附加权限，目录、MCP 工具发现和执行都检查完整权限集合。
- 绑定批量预载。日志库按站点 ID 聚合，查询数与站点数无关，同一来源 IP 跨站点别名只计一次。日志只有请求域名，站点归属采用当前绑定，精确域名优先于 Pingora 的单级通配域名。未匹配请求独立计数。
- 概览返回有界站点清单和两个明确的时间边界。逐请求审计仍使用日志工具，单独看趋势用流量指标工具。自动化流量指标直接查询所需聚合，避免控制台的路径、来源和浏览器统计开销。
