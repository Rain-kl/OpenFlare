# 定时任务仅记录失败日志

- `w_schedules.hide_success_log` 按记录配置。迁移只为种子记录 103（WAF IP 组同步）和 104（Uptime Kuma 同步）开启，并核对任务类型。更新 API 省略该字段时保留原值，支持列表中直接切换启用状态。
- Scheduler 使用 Asynq Header 传递该配置，保持业务 Payload 不变。同类型的其他定时任务和通过任务管理手动下发的任务不受影响；按入队时的配置执行。
- Worker 复用 Redis 执行日志缓冲。开启时，最终失败才创建执行记录并归档日志；暂时失败保留同一任务 ID 的缓冲，重试成功时删除缓冲。任务完成通知照常触发，既有历史记录不回写。
