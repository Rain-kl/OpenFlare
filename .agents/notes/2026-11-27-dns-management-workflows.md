# DNS 管理界面重组

DNS 解析按指向分组和同步记录组织。分组详情保留当前生效目标，将域名搜索、批量选择和添加操作放在成员列表顶部。筛选后的全选作用于当前结果，既有选择仍计入批量操作。

Cloudflare 连接保存和验证分别使用现有 API。保存成功后执行验证，验证失败时保留凭据供重试。DNS 账号列表标出当前连接使用的账号。

SmartDNS 将运行概览与委派设置分开，委派检查基于已保存的域名和 NS 配置。发现令牌接口会在缺少令牌时初始化配置，因此只在打开接入面板时调用。接入面板继续通过现有命令生成器支持 Linux、Docker、正式版和 Canary。自定义策略根据选中的编辑方式提交流程图或 JDM JSON，避免流程图优先编译时忽略 JSON 修改。

本地创建策略时发现旧表单提交的 `lowest_load` 和 `custom_jdm` 与 Go API 定义不一致。表单使用 API 接受的 `smart` 回退值和 `custom` 策略值，并显示全部受支持的回退选项。
