# 升级与维护

你会学到：如何升级 Server 与 Agent、如何清理观测数据，以及维护前后应该执行哪些验证命令。

升级前建议先确认当前站点配置、最近一次边缘节点应用结果和数据库备份策略。生产环境宜在节点连接和数据库迁移稳定时升级。

## Server 升级

拉取最新镜像升级

```bash
docker compose pull
docker compose up
```

如果是源码部署，重新启动 Server 后确认数据库迁移和快照编译成功。启用自动同步后，控制端会在启动时按数据库里已保存的配置生成站点快照，包括升级前已经保存的改动。

## Agent 升级

Agent 本地仅缓存运行配置与状态文件，不保存业务数据；升级时直接拉取最新镜像重建容器即可。具体部署命令与安装方式请参考 **[接入 Agent](./agent.md)**。
