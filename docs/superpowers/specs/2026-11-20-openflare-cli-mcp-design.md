# OpenFlare CLI 与 MCP 设计

## 用户操作与授权

一次浏览器授权对应一条实例连接。「只读排查」提供站点、域名、证书、节点、访问日志、流量和资源指标、性能策略查询。「日常运营」增加建站、域名登记与绑定、直连上游替换和性能参数更新。档位内的操作不需要 OpenFlare 逐条审批。客户端明确请求范围时，授权结果取所选档位与请求范围的交集。授权按实例生效，不按具体站点切分。

CLI 与 MCP 的 OAuth 授权码、S256 PKCE、令牌签发、刷新与撤销由 Ory Fosite 处理。授权界面复用控制台管理员会话，允许从客户端所请求的权限中逐项选择。CLI 与 MCP 的令牌受众独立。MCP 也接受系统现有的个人访问令牌；只有启用管理员权限的令牌可访问 MCP，并遵循现有令牌的轮换与撤销管理。浏览器登录需要管理员权限，令牌校验会重新确认账户状态。OAuth 访问令牌有效期为 15 分钟，授权最长持续 30 天。服务端持久化 OAuth 令牌签名的哈希；CLI 使用操作系统凭据库。

## 接入与演进

- 控制端内置 MCP Streamable HTTP，地址为 `/mcp`；CLI 请求 `/api/v1/automation`。两端复用操作实现和校验，不转发任意后台 URL。
- Swagger 的 `@ID` 决定工具名，`@x-automation` 声明 CLI 路径、权限与读写性质。路径和查询使用 Swagger 注解，JSON 请求体由带描述的结构体生成，输出必须指定具体 DTO。新增操作时复用或编写一条业务操作并绑定一次，运行 `make swagger` 后自动得到 REST、CLI 和 MCP 契约。
- 参数明确区分展示名、节点注册标识及对象记录 ID。CLI 参数重复、MCP 或 REST JSON 字段重复、未知字段、类型错误均拒绝。CLI 读写均使用登录保存的默认连接，可用 `--profile` 选择其他连接；服务端在写入前仍检查实例 ID 和操作摘要。修改操作契约后需同步更新 CLI；MCP 客户端可重新获取工具清单。
- 上游替换只更新目标站点的上游字段，新增域名绑定保留已有绑定；单项性能调整保留策略其他值。操作返回控制端保存状态，节点实际应用通过配置版本和应用结果核查。
- 工具描述和 schema 说明目标、参数来源、单位、取值及副作用。访问日志和用户控制的配置字段是返回数据，不可作为工具调用指令。日志查询不返回 UA 或 URL 查询串。

## 开通与验收

开通和操作步骤见 [CLI 与 MCP 指南](../../guide/automation.md)。发布工作流为 Linux、macOS 和 Windows 平台分别构建 CLI。服务端集成测试覆盖真实 SQLite 迁移、HTTPS、浏览器同意、OAuth 授权码交换、REST 和 MCP，验证建站、追加域名、换源、快照生成、性能参数更新、日志与指标查询、越权和参数错误。
