# OpenFlare Edge 性能策略

在控制台 **性能策略** 中为边缘节点配置工作线程、回源连接池、HTTP/2、TLS 与缓存存储参数。

## 创建并分配策略

1. 进入 **性能策略** 点击 **新建策略**（可从 `1C1G` / `2C2G` / `4C8G` 预设起步），调整运行与缓存参数后保存。
2. 点击 **分配节点** 勾选目标节点并保存；未显式分配的节点自动使用顶部 **默认策略**。

开启 **自动配置** 时，节点启动按可用 CPU 与内存上限（每线程 `768 MiB` 预算，最少 `1` 线程）自动计算工作线程数与空闲回源连接池；关闭后可手动指定。

回源超时、TLS 校验、上游 HTTP/2 与部分缓存开关保存后对新连接热生效；修改线程数、连接池容量、监听器或缓存容量上限时，节点会先排空连接再重载工作线程。

## 缓存存储设置

在策略 **缓存** 页签开启 **节点缓存**（同时须在站点规则开启缓存才会生效）：

| 参数 | 默认值 | 说明 |
| --- | ---: | --- |
| 内存缓存容量 | `128 MiB` | TinyUFO 内存缓存上限；开启磁盘缓存后用作热层 |
| 磁盘缓存容量 | `0 MiB` | 设为正数即启用磁盘缓存（存于状态目录 `http-cache`） |
| 磁盘缓存清理时间 | `172800` 秒 | 定期清理超过该时长未访问的缓存文件 |
| 磁盘并发读 / 写上限 | `32` / `16` | 超限时读请求直连回源、写响应跳过落盘 |

磁盘缓存初始化异常时自动回退至内存缓存，底层机制见 [OpenFlare Edge 架构设计](../design/pingora-edge-design.md)。
