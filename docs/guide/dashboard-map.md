# 首页地理分布

总览页使用单行标题与地图图例，标题下直接展示统计指标。数据每 60 秒自动刷新。

首页全球态势板第一排展示最近 24 小时的请求数、独立 IP、4xx 请求数和 5xx 请求数。请求数附带平均 QPS；4xx 和 5xx 分别显示占全部请求的比例。独立 IP 在全节点范围去重，所有指标均基于已有访问日志；没有请求时错误比例显示为 0%。

首页全球态势板默认展示点阵地球。拖动地球或聚焦后使用方向键，可查看不同地区；点击节点可进入节点详情，悬停显示请求量、错误数和运行状态。节点颜色沿用态势板的正常、承压和异常图例。

使用右上角 **3D／2D** 切换地球与平面地图。平面地图支持拖动和缩放。地图右侧的独立栏目展示最近 24 小时来源请求最多的七个国家，进度条以最高请求量为基准；没有来源数据时显示居中的空状态。地球上的来源国家按请求量高亮。

3D 与 2D 使用相同高度的展示区域，切换时保持布局稳定。地图配色跟随当前界面主题和明暗模式。窄屏下国家排行排列在地图下方。原右侧的平均 CPU、平均内存和高存储卡片由国家排行替代。

地图使用项目内置的地理数据。未配置坐标的节点沿用国家中心或预设落点，悬停信息会标明预设落点。
