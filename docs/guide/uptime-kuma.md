# Uptime Kuma 监控同步

将已启用的反向代理站点增量同步为 Uptime Kuma HTTP 监控项，并在站点停用或移除出范围时自动清理。

## 1. 配置集成

进入 **系统管理** > **系统设置** > **OpenFlare** > **Uptime Kuma 集成**，填写参数后保存（可点击 **立即同步** 立即触发）：

| 配置项 | 说明 | 默认值 |
| :--- | :--- | :--- |
| 启用 Uptime Kuma | 开启后台定时增量同步 | 关闭 |
| Uptime Kuma URL | 实例访问地址（需含 `http://` 或 `https://`，如 `https://kuma.example.com`） | 无 |
| 用户名 / 密码 | Uptime Kuma 管理员凭证（编辑时密码留空保留原值） | 无 |
| 同步间隔（分钟） | 后台差量对账周期 | `5` |
| 监控范围 | **全部站点**（所有已启用路由）或 **指定站点**（手动勾选） | 全部站点 |
| 检查间隔（秒） | Uptime Kuma 探测周期 | `60` |
| 重试次数 / 重试间隔（秒） | 判定故障前的重试次数与等待时间 | `0` / `60` |
| 请求超时（秒） | 单次探测超时阈值 | `48` |

## 2. 同步行为与日志

- 平台同步创建的监控项统一携带 `OpenFlare` 标签；对账和清理仅作用带该标签的条目，不影响手动监控项。
- 修改站点域名或探测参数会增量更新原有监控项，保留历史在线率；纯泛域名路由至少需含一个具体域名才会同步。
- **系统管理** > **任务列表** 中的 **OpenFlare Uptime Kuma Sync** 默认仅保留失败日志，可按需开启成功运行日志。

控制流程与差量匹配实现参见 [Uptime Kuma 监控同步设计](../design/kuma-design.md)。
