# 创建第一条反向代理规则

在管理端保存反向代理规则后，控制端自动通知在线的 OpenFlare Edge 同步配置。本指南使用 HTTP 站点验证首次同步。

---

## 准备工作

| 检查项 | 状态要求 |
| --- | --- |
| **Server** | 控制面板已正常启动，且能顺利登录管理端 |
| **Agent** | 至少有一个边缘节点处于在线状态（可在「节点管理」中确认） |
| **源站** | 确认后端源站服务可从边缘节点宿主机正常访问 |
| **域名/测试** | 域名已完成 DNS 解析，或者准备在客户端使用本地 hosts / curl 命令行 Host 头进行测试 |

---

## 步骤一：创建首个网站配置

进行首次验证时，可先创建基础 HTTP 反向代理站点：

1. 登录控制面板，进入左侧导航 **「网站管理」->「域名列表」**，点击 **「新增 Zone」**。
2. 填写域名配置：
   * **域名**：输入用于测试的域名（如 `first.example.com`）。
   * **绑定证书**：选择不绑定证书（作为 HTTP 快速验证）。
   * 点击保存，完成域名登记。
3. 进入左侧导航 **「规则管理」**，点击 **「新建规则」**：
   * **规则名称**：输入简易标识（如 `first-app-route`）。
   * **域名匹配**：填入测试域名（如 `first.example.com`）。
   * 在下方 **「反向代理」** 选项卡中，配置 **回源方式** 为「直连上游」。
   * **上游地址**：填写后端服务地址（如测试专用的 `http://httpbin.org`）。
   * 点击保存创建规则。

> [!TIP]
> **关于 HTTPS 与证书准备**
> 本节仅引导快速部署基础 HTTP 规则。若需要导入已有证书或通过 ACME 协议向 CA 自动申请证书并开启 443 端口 HTTPS 代理，请前往 [新建反代配置](./proxy-config.md) 查阅详细步骤。

---

## 步骤二：验证边缘节点配置

在线节点收到通知后立即同步。WebSocket 断开时，节点在周期心跳中发现新配置。

1. **管理端验证**：进入「节点管理」-> 点击节点进入详情，确认「应用记录」中最近一次配置应用成功。
2. **边缘节点验证**：在边缘节点宿主机上通过日志检查应用情况：
   ```bash
   journalctl -u openflare-edge -n 50 --no-pager
   ```
3. **连通性测试**：
   在客户端使用 `curl` 携带测试 Host 请求边缘节点的 IP 地址进行验证：
   ```bash
   curl -I -H "Host: first.example.com" http://AGENT_NODE_IP
   ```
   返回的状态码应与源站响应一致。
